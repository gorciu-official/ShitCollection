# The original, batch version of JUAMP game

This is the original version of the [JUAMP game](https://github.com/gorciu-official/JUAMP) written in Batch, that, years later, inspired me to write a legendary rewrite in C++.

Please note that this code was written as one of my first projects, so:

- it contains a lot of references to my private life, that got censored in the source code (I didn't separate things I would want to be public and thing I would want to be private back then);
- it contains code snippets that are deprecated or could be done better;
- I didn't understand some key concepts, so... expect weird dialogoues, inaccurate texts and outdated pricing;
- it maybe ugly and unreadable.

It's worth noting that messages `REDACTED` and `2026 UPDATE` were added just before making this project open-source, so it's better to read them.

This game best runs on Windows 10.

**Running this game in Wine might require patching the code to use `timeout` instead of `ping localhost -n`.**

**Running this game in Windows 11 might require patching folder names like `Desktop` to their localised versions.**

The original JUAMP game contains multiple pieces of copied code from [this unlicensed game](https://www.youtube.com/watch?v=CzOylI6MiqQ).

The original JUAMP game contained audio files that were dropped in the post-processing before making this open-source, because I probably don't have required licenses to use this for this game. You can contact me to get original JUAMP with soundtrack.
